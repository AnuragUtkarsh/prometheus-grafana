WHAT IS GRAFANA?
===============================================================================

Grafana is an Open Source Visualization Tool.

Purpose

- Dashboards
- Charts
- Graphs
- Monitoring
- Alerting
- Reports

Grafana DOES NOT store metrics.

Grafana reads metrics from Datasources like

- Prometheus
- Elasticsearch
- Loki
- InfluxDB
- MySQL
- PostgreSQL

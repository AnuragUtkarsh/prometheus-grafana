INSTALLATION METHOD
===============================================================================

Prometheus Installation can be done using

1. APT Repository

2. Binary Installation (Production Recommended)

We used Binary Installation.

===============================================================================
STEP 1 : CREATE USER
===============================================================================

sudo useradd --no-create-home \
--shell /usr/sbin/nologin prometheus

Purpose

Dedicated Service Account

No Login

More Secure

===============================================================================
STEP 2 : CREATE DIRECTORIES
===============================================================================

sudo mkdir /etc/prometheus

sudo mkdir /var/lib/prometheus

Purpose

/etc/prometheus

Configuration Files

--------------------------------

/var/lib/prometheus

Stores Time Series Database

===============================================================================
STEP 3 : DOWNLOAD
===============================================================================

cd /tmp

wget https://github.com/prometheus/prometheus/releases/download/v3.11.3/prometheus-3.11.3.linux-amd64.tar.gz

===============================================================================
STEP 4 : EXTRACT
===============================================================================

tar -xzf prometheus-3.11.3.linux-amd64.tar.gz

cd prometheus-3.11.3.linux-amd64

===============================================================================
STEP 5 : VERIFY FILES
===============================================================================

ls

Expected

LICENSE

NOTICE

prometheus

promtool

prometheus.yml

===============================================================================
STEP 6 : COPY BINARIES
===============================================================================

sudo cp prometheus /usr/local/bin/

sudo cp promtool /usr/local/bin/

Verify

prometheus --version

promtool --version

===============================================================================
STEP 7 : COPY CONFIGURATION
===============================================================================

sudo cp prometheus.yml /etc/prometheus/

===============================================================================
STEP 8 : CHANGE OWNERSHIP
===============================================================================

sudo chown -R prometheus:prometheus /etc/prometheus

sudo chown -R prometheus:prometheus /var/lib/prometheus

sudo chown prometheus:prometheus /usr/local/bin/prometheus

sudo chown prometheus:prometheus /usr/local/bin/promtool

===============================================================================
STEP 9 : CREATE SYSTEMD SERVICE
===============================================================================

File

/etc/systemd/system/prometheus.service

Contents

[Unit]

Description=Prometheus

Documentation=https://prometheus.io/docs/

After=network-online.target

[Service]

User=prometheus

Group=prometheus

Type=simple

ExecStart=/usr/local/bin/prometheus \
--config.file=/etc/prometheus/prometheus.yml \
--storage.tsdb.path=/var/lib/prometheus

Restart=on-failure

[Install]

WantedBy=multi-user.target

===============================================================================
STEP 10 : START SERVICE
===============================================================================

sudo systemctl daemon-reload

sudo systemctl enable prometheus

sudo systemctl start prometheus

===============================================================================
STEP 11 : VERIFY
===============================================================================

systemctl status prometheus

ss -lntp | grep 9090

Expected

LISTEN

9090

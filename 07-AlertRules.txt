WHAT IS ALERT RULE?
===============================================================================

Alert Rule is a condition evaluated by Prometheus.

If condition becomes TRUE

↓

Alert becomes

Pending

↓

After specified time

↓

Firing

↓

Sent to Alertmanager

===============================================================================
CPU ALERT
===============================================================================

groups:

- name: linux_alerts

  rules:

  - alert: HighCPUUsage

    expr:

      100 -

      (

      avg by(instance)

      (

      rate(node_cpu_seconds_total{mode="idle"}[5m])

      )

      *100

      )

      > 80

    for: 2m

    labels:

      severity: warning

    annotations:

      summary: High CPU Usage

      description: CPU Usage above 80%

===============================================================================
MEMORY ALERT
===============================================================================

- alert: HighMemoryUsage

  expr:

  (

  1 -

  (

  node_memory_MemAvailable_bytes

  /

  node_memory_MemTotal_bytes

  )

  )

  *100

  > 90

  for: 2m

===============================================================================
DISK ALERT
===============================================================================

- alert: DiskUsageHigh

  expr:

  100 -

  (

  node_filesystem_avail_bytes

  /

  node_filesystem_size_bytes

  *100

  )

  > 85

  for: 5m

===============================================================================
NODE DOWN ALERT
===============================================================================

- alert: NodeDown

  expr:

  up==0

  for: 1m

===============================================================================
LOAD ALERT
===============================================================================

- alert: HighLoad

  expr:

  node_load1>5

  for: 2m

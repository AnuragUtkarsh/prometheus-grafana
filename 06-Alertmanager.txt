WHAT IS ALERTMANAGER?
===============================================================================

Alertmanager is a notification component of Prometheus.

It receives alerts from Prometheus and sends notifications to different
receivers.

Examples

- Email
- Slack
- Microsoft Teams
- PagerDuty
- Webhook

Alertmanager DOES NOT collect metrics.

Alertmanager DOES NOT evaluate rules.

Alertmanager ONLY handles notifications.

INSTALLATION
===============================================================================

Create User

sudo useradd --no-create-home \
--shell /usr/sbin/nologin alertmanager

-------------------------------------------------------------------------------

Create Directories

sudo mkdir /etc/alertmanager

sudo mkdir /var/lib/alertmanager

-------------------------------------------------------------------------------

Download Binary

Example Version

alertmanager-0.32.1.linux-amd64.tar.gz

-------------------------------------------------------------------------------

Extract

tar -xzf alertmanager-0.32.1.linux-amd64.tar.gz

-------------------------------------------------------------------------------

Copy Binary

sudo cp alertmanager /usr/local/bin/

sudo cp amtool /usr/local/bin/

-------------------------------------------------------------------------------

Copy Configuration

sudo cp alertmanager.yml /etc/alertmanager/

-------------------------------------------------------------------------------

Ownership

sudo chown -R alertmanager:alertmanager /etc/alertmanager

sudo chown -R alertmanager:alertmanager /var/lib/alertmanager

sudo chown alertmanager:alertmanager /usr/local/bin/alertmanager

sudo chown alertmanager:alertmanager /usr/local/bin/amtool

===============================================================================
SMTP CONFIGURATION
===============================================================================

File

/etc/alertmanager/alertmanager.yml

Example

global:

  smtp_smarthost: 'smtp.gmail.com:587'

  smtp_from: 'yourmail@gmail.com'

  smtp_auth_username: 'yourmail@gmail.com'

  smtp_auth_password: 'APP_PASSWORD'

  smtp_require_tls: true

route:

  receiver: email-alert

receivers:

- name: email-alert

  email_configs:

  - to: 'receiver@gmail.com'

    send_resolved: true

===============================================================================
ROUTE
===============================================================================

===============================================================================
SEND_RESOLVED
===============================================================================

send_resolved: true

Meaning

When alert is resolved

↓

Another Email will be sent.

===============================================================================
GROUPING
===============================================================================

Multiple alerts

↓

Group together

↓

Single Notification

Instead of

100 Emails

===============================================================================
SILENCE
===============================================================================

Temporarily suppress alerts.

Example

Maintenance Window

===============================================================================
INHIBITION
===============================================================================

Suppress child alerts

if

Parent Alert already firing.

Example

Server Down

↓

CPU Alert

Disk Alert

Memory Alert

No need to send all.

WHAT IS PROMQL?
===============================================================================

PromQL (Prometheus Query Language) is the query language used to retrieve,
filter, calculate and aggregate metrics stored inside Prometheus TSDB.

Purpose

- View Metrics
- Calculate CPU Usage
- Calculate Memory Usage
- Calculate Disk Usage
- Create Dashboards
- Create Alerts

===============================================================================
BASIC QUERY
===============================================================================

up

Meaning

Shows whether target is UP or DOWN.

Result

1

↓

Target UP

0

↓

Target DOWN

MOST IMPORTANT FUNCTIONS
===============================================================================

rate()

Calculates Per Second Rate

Mostly used for Counters

Example

rate(node_cpu_seconds_total[5m])

------------------------------------------------------

irate()

Instant Rate

Used for Live Traffic

------------------------------------------------------

increase()

Total Increase

Example

increase(node_network_receive_bytes_total[5m])

------------------------------------------------------

sum()

Total

Example

sum(node_memory_MemTotal_bytes)

------------------------------------------------------

avg()

Average

Example

avg(node_load1)

------------------------------------------------------

max()

Maximum Value

------------------------------------------------------

min()

Minimum Value

------------------------------------------------------

count()

Count Number of Metrics
